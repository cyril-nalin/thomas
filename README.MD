# BeThom

BeThom est un site web créé pour Thomas qui souhaite devenir graphiste en freelance.

## Auteurs

Emeric (coursenia) / Nalin Cyril

## Installation

HTML — structure et contenu de la page web  
CSS — mise en forme et présentation de la page

## Installation

Pour la version github:  
télécharger le dépôt, ouvrir le dossier dans VS Code, lancer le projet via le navigateur intégré.  

Pour la version en ligne:  
Aucune installation n'est nécessaire, utiliser n'importe quel navigateur web et se rendre sur la page http://slimshady451.free.fr/BeThom/.
